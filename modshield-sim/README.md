# ModShield AI — Assistant Simulation

ModShield AI is a browser-based simulated assistant experience for explaining suspicious-message and link risk signals. It provides a transparent, safety-first assessment and never opens submitted links or collects credentials.

## Run locally

No installation is required. Open `index.html` in a modern browser, or serve this folder with any static file server.

## Demo flow

Paste a message or URL into the assistant. The demo identifies common risk signals such as urgency, credential requests, payment prompts, and links, then returns safer next steps.

## Responsible-use note

The tool is educational triage only. It is not a malware scanner or a substitute for an official incident-response process.
